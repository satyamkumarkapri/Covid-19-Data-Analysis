M1: Data Preprocessing & Cleaning

Before analyzing data, we must clean it to ensure accuracy. Real-world data is often messy, containing errors or gaps. Here is how our automated pipeline prepares the raw Johns Hopkins dataset:

Missing Values

Days where countries failed to report cases result in missing values (NaN). We resolve this using mathematical interpolation and .fillna(0) to ensure continuous time-series data without gaps.

Duplicate Values

Some countries report data by province, resulting in overlapping rows. We aggregate and merge these using .groupby() to guarantee exactly one clean row per country per day.

Outlier Detection

Sudden massive negative cases often appear due to historical data corrections by governments. We bound our data and clip negative daily spikes to prevent them from skewing our statistical models.
